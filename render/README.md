# Render aprobado — Ítaca Catálogo (Propuesta 2)

Referencia visual a 390×844 (celular). Cada pantalla viene en dos formatos:
- `.png`: cómo debe verse.
- `.html`: el mismo diseño en HTML estático, con los colores, tipografías y espaciados exactos. Las imágenes están en `img/`.

Úsalos como **referencia de diseño**, no como código de producción: hay que reconstruir cada pantalla en React + Tailwind (ver PLAN §8–9).
Los pedidos, nombres y montos de ejemplo son inventados.

| Archivo | Pantalla |
|---|---|
| 01-portada | Portada (tocar o deslizar para entrar) |
| 02-categorias | Categorías + Personalización |
| 03-categoria | Dentro de una categoría (fotos de modelo, sin precios) |
| 04-producto | Producto |
| 05-personalizacion | Personalización |
| 06-pedido | Tu pedido (entrega y envío) |
| 07-modo-tere | Modo Tere |
